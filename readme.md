# EasyPack Appstarter

---

This is the application starter for EasyPack framework.

### Starting an application using this repo

1. First, download the repo, either directly or by cloning.
2. Run **composer install** for the app dependencies.
3. Configure your web server to have **public** folder as the web root.
4. Create a new **.env** file and enter your config data.
5. Rewrite all requests to [AltoRouter].

[AltoRouter]: <https://altorouter.com/usage/rewrite-requests.html>
